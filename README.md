# Solución de para la sincronización de turnos médicos
En el presente se detalla una resolución a una problemática de concurrencia entre procesos utilizando las herramientas conceptuales de sincronización por Semáforos en Java.
## Objetivos
* Dar una solución realizada en Java que sea libre de Deadlocks.
* Analizar si la solución propuesta en el punto anterior es libre de Livelocks.
* Evitar la inanición en los hilos.
